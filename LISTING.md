# Listing your firmware

The README lists firmware that uses this base. To be listed:

1. Open an issue with the "List your firmware" form.
2. Give the project link, the device, the licence, and a description of up to 200 characters.
3. The project must be public and say that it uses this base.

We write the entry from your text and may shorten it. We do not test, review or endorse listed
firmware, and a listing is not a statement about its quality or its licence compliance.

We may decline or remove an entry if the link is dead, the description is misleading, or the
project claims to be official.

You do not need to be listed to use the base.
